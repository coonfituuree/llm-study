REPRODUCIBLE BY DESIGN

Data first.
Conclusions follow.

Every number is calculated from test results. The PDF is used for comparison; the spreadsheet supplies the observations.

01

Pass rate

For each task, model and language:

rt,m,l = passed / total

For example, 5/12 = 41.67%. Values are rounded for display only.

02

Mean across tasks

The default mode matches the PDF. Each task and each selected language has equal weight.

Macro = 100 × Σ r / (n × L)

n is the number of complete tasks; L is the number of selected languages.

03

Mean across all tests

An alternative mode: tasks with more tests carry more weight.

Micro = 100 × Σ passed / Σ total

Results may therefore differ from the PDF. This is a separate aggregation method.

04

Paired comparison

Δ = Sonnet − Sol, in percentage points. Task wins compare the mean pass rates across selected languages.

Δt = 100 × mean(rSonnet − rSol)

Differences below 10⁻⁹ percentage points count as ties. These are descriptive statistics, without significance testing.

DATA QUALITY

How the spreadsheet is processed

A fully solved task passes 100% of tests in every selected language. A partial result means 0 < passed < total. A cell is a task × model × language observation. Complete tasks require all six results, even when only one language is selected.

Interpretation limits

This study uses one set of 80 tasks with one result per model × language pair. The mean fraction of passed tests is neither the probability of solving a new task nor a pass@k metric. Differences depend on difficulty, platform and test coverage; a causal language effect and statistical significance have not been established.
