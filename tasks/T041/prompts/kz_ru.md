# Екі сұрыпталған массивтің медианасы

Даны два отсортированных массива `nums1` и `nums2` размера `m` и `n` соответственно, верните **медиану** двух отсортированных массивов.

Общая временная сложность должна быть `O(log (m+n))`.

## 1-мысал:

**Кіріс:** nums1 = [1,3], nums2 = [2]  
**Шығыс:** 2.00000  
**Түсіндірме:** объединённый массив = [1,2,3] и медиана равна 2.

## 2-мысал:

**Кіріс:** nums1 = [1,2], nums2 = [3,4]  
**Шығыс:** 2.50000  
**Түсіндірме:** объединённый массив = [1,2,3,4] и медиана равна (2 + 3) / 2 = 2.5.

## Шектеулер:

- nums1.length == m
- nums2.length == n
- 0 <= m <= 1000
- 0 <= n <= 1000
- 1 <= m + n <= 2000
- -10⁶ <= nums1[i], nums2[i] <= 10⁶
