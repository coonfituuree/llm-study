# Екі сұрыпталған массивтің медианасы

Сәйкесінше `m` және `n` өлшемді екі сұрыпталған `nums1` және `nums2` массивтері берілген, екі сұрыпталған массивтің **медианасын** қайтарыңыз.

Жалпы орындалу уақыты күрделілігі `O(log (m+n))` болуы керек.

## 1-мысал:

**Кіріс:** nums1 = [1,3], nums2 = [2]  
**Шығыс:** 2.00000  
**Түсіндірме:** біріктірілген массив = [1,2,3] және медиана 2.

## 2-мысал:

**Кіріс:** nums1 = [1,2], nums2 = [3,4]  
**Шығыс:** 2.50000  
**Түсіндірме:** біріктірілген массив = [1,2,3,4] және медиана (2 + 3) / 2 = 2.5.

## Шектеулер:

- nums1.length == m
- nums2.length == n
- 0 <= m <= 1000
- 0 <= n <= 1000
- 1 <= m + n <= 2000
- -10⁶ <= nums1[i], nums2[i] <= 10⁶
