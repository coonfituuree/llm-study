# Элементті жою

`nums` бүтін сандар массиві және `val` бүтін саны берілген.  
Нужно удалить все вхождения `val` из массива `nums` **на месте (in-place)**. Порядок элементов может измениться. Затем верните количество элементов в `nums`, которые не равны `val`.

Пусть количество элементов в `nums`, не равных `val`, будет `k`. Чтобы решение было принято, нужно:

- Изменить массив `nums` так, чтобы первые `k` элементов содержали элементы, не равные `val`. Оставшиеся элементы и размер массива не важны.
- Вернуть `k`.

## 1-мысал:

Кіріс: nums = [3,2,2,3], val = 3  
Шығыс: 2, nums = [2,2,_,_]  
Түсіндірме: Функция должна вернуть k = 2, первые два элемента nums должны быть 2.  
Элементы после возвращённого k не важны (поэтому они обозначены _).

## 2-мысал:

Кіріс: nums = [0,1,2,2,3,0,4,2], val = 2  
Шығыс: 5, nums = [0,1,4,0,3,_,_,_]  
Түсіндірме: Функция должна вернуть k = 5, первые пять элементов nums должны содержать 0, 0, 1, 3 и 4.  
Пять элементов могут быть в любом порядке.  
Элементы после возвращённого k не важны.

## Шектеулер:

- 0 <= nums.length <= 100
- 0 <= nums[i] <= 50
- 0 <= val <= 100
