# Элементті жою (Remove Element)

`nums` бүтін сандар массиві және `val` бүтін саны берілген. `nums` массивінен `val`-дың барлық кездесулерін **орында (in-place)** жойыңыз. Элементтердің реті өзгеруі мүмкін. Содан кейін `nums` массивіндегі `val`-ға тең емес элементтердің санын қайтарыңыз.

`nums` массивіндегі `val`-ға тең емес элементтердің санын `k` деп есептесек, қабылдану үшін мыналарды орындау керек:

- `nums` массивін өзгертіңіз, сондықтан `nums`-тың алғашқы `k` элементі `val`-ға тең емес элементтерді қамтиды. `nums`-тың қалған элементтері мен өлшемі маңызды емес.
- `k`-ны қайтарыңыз.

## 1-мысал:

**Кіріс:** `nums = [3,2,2,3], val = 3`  
**Шығыс:** `2, nums = [2,2,_,_]`  
**Түсіндірме:** Функцияңыз `k = 2` қайтаруы керек, `nums`-тың алғашқы екі элементі `2` болуы керек.  
Қайтарылған `k`-дан кейінгі элементтер маңызды емес (сондықтан олар `_` деп белгіленген).

## 2-мысал:

**Кіріс:** `nums = [0,1,2,2,3,0,4,2], val = 2`  
**Шығыс:** `5, nums = [0,1,4,0,3,_,_,_]`  
**Түсіндірме:** Функцияңыз `k = 5` қайтаруы керек, `nums`-тың алғашқы бес элементі `0, 0, 1, 3, 4` болуы керек.  
Бес элемент кез келген ретпен болуы мүмкін.  
Қайтарылған `k`-дан кейінгі элементтер маңызды емес.

## Шектеулер:

- `0 <= nums.length <= 100`
- `0 <= nums[i] <= 50`
- `0 <= val <= 100`
