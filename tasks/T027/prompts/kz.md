# 33. Айналдырылған сұрыпталған массивте іздеу

**Орташа**

`nums` бүтін сандар массиві өсу ретімен сұрыпталған (**қайталанбайтын** мәндермен).

Функцияға берілмес бұрын `nums` белгісіз `k` индексінде **солға айналдырылған** болуы мүмкін (`1 <= k < nums.length`), нәтижесінде массив `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]` болады (**0-индекстелген**). Мысалы, `[0,1,2,4,5,6,7]` 3 индекске солға айналдырылып `[4,5,6,7,0,1,2]` болуы мүмкін.

Айналдырудан **кейінгі** `nums` массиві және `target` бүтін саны берілген. `target`-тің `nums`-тегі индексін қайтарыңыз, егер ол жоқ болса `-1` қайтарыңыз.

Алгоритм `O(log n)` уақыт күрделілігінде болуы керек.

### 1-мысал:
```
Кіріс: nums = [4,5,6,7,0,1,2], target = 0
Шығыс: 4
```

### 2-мысал:
```
Кіріс: nums = [4,5,6,7,0,1,2], target = 3
Шығыс: -1
```

### 3-мысал:
```
Кіріс: nums = [1], target = 0
Шығыс: -1
```

### Шектеулер:
- 1 <= nums.length <= 5000
- -10⁴ <= nums[i] <= 10⁴
- nums-тің барлық мәндері **бірегей**.
- nums өсу ретімен сұрыпталған массив, мүмкін айналдырылған.
- -10⁴ <= target <= 10⁴
