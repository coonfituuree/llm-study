# Дұрыс жақшалар

## Тапсырма

Сізге тек келесі жақша таңбаларынан тұратын `s` жолы беріледі:

- `(`
- `)`
- `{`
- `}`
- `[`
- `]`

Жақшалар тізбегінің дұрыс екенін анықтаңыз.

Тізбек дұрыс деп есептеледі, егер әрбір ашылатын жақша дәл сол түрдегі жабылатын жақшамен жұптасса және барлық жақшалар дұрыс ретпен жабылса.

Егер тізбек дұрыс болса, `True`, әйтпесе `False` қайтарыңыз.

## Мысалдар

```text
Кіріс: s = "()"
Шығыс: true
```

```text
Кіріс: s = "()[]{}"
Шығыс: true
```

```text
Кіріс: s = "(]"
Шығыс: false
```

```text
Кіріс: s = "([])"
Шығыс: true
```

```text
Кіріс: s = "([)]"
Шығыс: false
```

## Шектеулер

- `1 <= len(s) <= 10^4`
- `s` жолы тек `()[]{}` таңбаларынан тұрады.
