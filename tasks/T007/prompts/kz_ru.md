# Дұрыс жақшалар / Valid Parentheses

## Тапсырма

Сізге тек `(`, `)`, `{`, `}`, `[`, `]` символдарынан тұратын `s` жолы беріледі.

Нужно определить, является ли последовательность скобок дұрыс.

Тізбек valid болып саналады, егер әрбір открывающая скобка дәл сондай түрдегі закрывающая скобкамен жұптасса және скобкалар правильном порядке жабылса.

Егер последовательность дұрыс болса, `True`, әйтпесе `False` қайтарыңыз.

## Мысалдар

```text
Input: s = "()"
Output: true
```

```text
Input: s = "()[]{}"
Output: true
```

```text
Input: s = "(]"
Output: false
```

```text
Input: s = "([])"
Output: true
```

```text
Input: s = "([)]"
Output: false
```

## Шектеулер

- `1 <= len(s) <= 10^4`
- `s` тек `()[]{}` символдарынан тұрады.
