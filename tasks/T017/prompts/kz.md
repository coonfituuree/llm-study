# A. Bit++

Уақыт шектеуі: 1 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: stdin  
шығыс: stdout

Bitland-тың классикалық бағдарламалау тілі — Bit++. Бұл тіл өте ерекше және күрделі.

Тіл соншалықты ерекше, өйткені онда тек бір айнымалы бар, ол *x* деп аталады. Сондай-ақ, екі операция бар:

- ++ операциясы *x* айнымалысының мәнін 1-ге арттырады.
- -- операциясы *x* айнымалысының мәнін 1-ге азайтады.

Bit++ тіліндегі оператор — бұл дәл бір операциядан және бір *x* айнымалысынан тұратын тізбек. Оператор бос орынсыз жазылады, яғни ол тек "+", "-", "X" таңбаларын қамтуы мүмкін. Операторды орындау оның құрамындағы операцияны қолдануды білдіреді.

Bit++ бағдарламасы — бұл орындалуы керек операторлар тізбегі. Бағдарламаны орындау оның құрамындағы барлық операторларды орындауды білдіреді.

Сізге Bit++ тіліндегі бағдарлама берілген. *x*-тің бастапқы мәні 0. Бағдарламаны орындаңыз және оның соңғы мәнін табыңыз (*x* айнымалысының мәні осы бағдарлама орындалғаннан кейін).

## Кіріс

Бірінші жолда бір бүтін сан *n* бар (1 ≤ *n* ≤ 150) — бағдарламадағы операторлар саны.

Келесі *n* жолдың әрқайсысында бір оператор бар. Әрбір оператор дәл бір операцияны (++ немесе --) және дәл бір *x* айнымалысын («X» әрпімен белгіленген) қамтиды. Осылайша, бос операторлар жоқ. Операция мен айнымалы кез келген ретпен жазылуы мүмкін.

## Шығыс

Бір бүтін санды шығарыңыз — *x*-тің соңғы мәні.

## Мысалдар

**Кіріс**
```
1
++X
```

**Шығыс**
```
1
```

**Кіріс**
```
2
X++
--X
```

**Шығыс**
```
0
```
