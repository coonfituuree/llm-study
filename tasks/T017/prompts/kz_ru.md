# A. Bit++

Уақыт шектеуі: 1 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: stdin  
шығыс: stdout

Классический язык программирования Bitland — это Bit++. Этот язык настолько своеобразный и сложный.

Тіл соншалықты ерекше, потому что в нём ровно одна переменная, называемая *x*. Также есть две операции:

- Операция ++ увеличивает значение переменной *x* на 1.
- Операция -- уменьшает значение переменной *x* на 1.

Оператор в языке Bit++ — это последовательность, состоящая ровно из одной операции и одной переменной *x*. Оператор жазылады без пробелов, то есть он может содержать только символы "+", "-", "X". Выполнение оператора означает применение содержащейся в нём операции.

Программа на Bit++ — это последовательность операторов, каждый из которых нужно выполнить. Выполнение программы означает выполнение всех содержащихся в ней операторов.

Сізге программа на языке Bit++ берілген. Начальное значение *x* равно 0. Выполните программу и найдите её конечное значение (значение переменной после выполнения этой программы).

## Кіріс

Бірінші жолда бір бүтін сан *n* бар (1 ≤ *n* ≤ 150) — количество операторов в программе.

Следующие *n* строк содержат по одному оператору. Каждый оператор содержит ровно одну операцию (++ или --) и ровно одну переменную *x* (обозначенную буквой «X»). Таким образом, пустых операторов нет. Операция и переменная могут быть записаны в любом порядке.

## Шығыс

Выведите одно целое число — конечное значение *x*.

## Мысалдар

**Кіріс**
```
1
++X
```

**Шығыс**
```
1
```

**Кіріс**
```
2
X++
--X
```

**Шығыс**
```
0
```
