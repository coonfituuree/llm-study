# 28. Жолдағы бірінші кездесудің индексін табу

**Оңай**

Екі жол берілген: `needle` және `haystack`. `needle`-дің `haystack`-тегі бірінші кездесуінің индексін қайтарыңыз. Егер `needle` `haystack`-тің бөлігі болмаса, `-1` қайтарыңыз.

### 1-мысал:
```
Кіріс: haystack = "sadbutsad", needle = "sad"
Шығыс: 0
Түсіндірме: "sad" 0 және 6 индекстерінде кездеседі.
Бірінші кездесу 0 индексінде, сондықтан 0 қайтарамыз.
```

### 2-мысал:
```
Кіріс: haystack = "leetcode", needle = "leeto"
Шығыс: -1
Түсіндірме: "leeto" "leetcode"-те кездеспейді, сондықтан -1 қайтарамыз.
```

### Шектеулер:
- 1 <= haystack.length, needle.length <= 10⁴
- haystack және needle тек кіші ағылшын әріптерінен тұрады.
