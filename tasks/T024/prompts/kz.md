# 3. Қайталанбайтын таңбалары бар ең ұзын ішкі жол

**Орташа**

`s` жолы берілген. Қайталанбайтын таңбалары бар **ең ұзын ішкі жолдың** ұзындығын табыңыз.

### 1-мысал:
```
Кіріс: s = "abcabcbb"
Шығыс: 3
Түсіндірме: Жауап — "abc", ұзындығы 3.
"ескерту": "bca" және "cab" да дұрыс жауаптар.
```

### 2-мысал:
```
Кіріс: s = "bbbbb"
Шығыс: 1
Түсіндірме: Жауап — "b", ұзындығы 1.
```

### 3-мысал:
```
Кіріс: s = "pwwkew"
Шығыс: 3
Түсіндірме: Жауап — "wke", ұзындығы 3.
Ескерту: жауап ішкі жол болуы керек, "pwke" — бұл subsequence, ішкі жол емес.
```

### Шектеулер:
- 0 <= s.length <= 10⁵
- s ағылшын әріптерінен, цифрлардан, символдардан және бос орындардан тұрады.
