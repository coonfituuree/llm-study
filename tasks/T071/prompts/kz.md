# Ағаш сұраныстары

## Тапсырма

Сізге `n` төбеден тұратын түбірлі ағаш берілген. `1`-төбе — ағаштың түбірі.

Әрбір төбеде ағылшын әліпбиінің бір кіші әрпі жазылған.

Әрбір `(v, h)` сұранысы үшін келесі шарттарға сай барлық төбелерді қарастырыңыз:

- олар `v` төбесінің ішкі ағашында орналасқан;
- олардың тереңдігі дәл `h`-ке тең.

Осы төбелердегі барлық әріптердің орнын еркін ауыстыруға болады.

Барлық әріпті пайдаланып палиндром құруға болатынын анықтаңыз.

Бос жол да палиндром болып саналады.

## Кіріс

Бірінші жолда `n` және `m` бүтін сандары беріледі — төбелер саны және сұраныстар саны.

Екінші жолда `n - 1` бүтін сан беріледі:

```text
p2 p3 ... pn
```

мұндағы `pi` — `i` төбесінің ата-анасы.

Келесі жолда `n` кіші ағылшын әрпінен тұратын жол беріледі. `i`-ші әріп `i` төбесіне тиесілі.

Келесі `m` жолдың әрқайсысында екі бүтін сан беріледі:

```text
v h
```

## Шығыс

Әрбір сұраныс үшін:

- палиндром құруға болса `Yes`;
- әйтпесе `No`

шығарыңыз.

## Шектеулер

- `1 <= n, m <= 500000`
- `1 <= pi < i`
- `1 <= v, h <= n`
