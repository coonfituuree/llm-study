# Ағаш сұраныстары / Tree Requests

## Тапсырма

Сізге `n` вершинадан тұратын rooted tree берілген. `1`-вершина — корень.

Әрбір вершинада бір lowercase English letter жазылған.

Әрбір `(v, h)` запрос үшін келесі шарттарға сәйкес вершинадарды қарастырыңыз:

- олар `v` вершинасының subtree ішінде орналасқан;
- олардың depth мәні дәл `h`-ке тең.

Осы вершинадардағы барлық әріптерді кез келген порядке переставить етуге болады.

Барлық әріптерді қолданып palindrome құру мүмкіндігін анықтаңыз.

Пустая строка да palindrome болып есептеледі.

## Кіріс

Бірінші строкада `n` және `m` беріледі — вершина саны және запрос саны.

Екінші строкада `n - 1` бүтін сан беріледі:

```text
p2 p3 ... pn
```

мұндағы `pi` — `i` вершинасының parent мәні.

Келесі строкада `n` lowercase English letters-тан тұратын жол беріледі. `i`-ші символ `i` вершинасына тиесілі.

Келесі `m` строкада:

```text
v h
```

форматындағы запрос беріледі.

## Шығыс

Әрбір запрос үшін:

- егер palindrome жасауға болса `Yes`;
- иначе `No`

шығарыңыз.

## Шектеулер

- `1 <= n, m <= 500000`
- `1 <= pi < i`
- `1 <= v, h <= n`

## Мысал

```text
Input
6 5
1 1 1 3 3
zacccd
1 1
3 3
4 1
6 1
1 2

Output
Yes
No
Yes
Yes
Yes
```
