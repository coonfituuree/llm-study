# 88. Сұрыпталған массивтерді біріктіру (Тек қазақша)

**Оңай**  
Тақырыптар  
Компаниялар  
Кеңес  

Сізге екі бүтін сандар массиві **nums1** және **nums2** берілген, олар өспелі емес (non-decreasing) ретпен сұрыпталған, және екі бүтін сан **m** мен **n**, олар сәйкесінше nums1 және nums2-дегі элементтер санын білдіреді.

nums1 және nums2-ні бір массивке біріктіру керек, ол массив өспелі емес ретпен сұрыпталған болуы тиіс.

Соңғы сұрыпталған массивті функция қайтармауы керек, керісінше оны **nums1** массивінің ішіне сақтау керек. Ол үшін nums1-дің ұзындығы **m + n** болады, мұндағы алғашқы **m** элемент — біріктіруге тиіс элементтер, ал соңғы **n** элемент 0-ге тең және оларды елемеу керек. nums2-нің ұзындығы **n**.

### 1-мысал:
```
Кіріс: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
Шығыс: [1,2,2,3,5,6]
Түсіндірме: Біз біріктіретін массивтер [1,2,3] және [2,5,6].
Біріктіру нәтижесі [1,2,2,3,5,6], мұндағы асты сызылған элементтер nums1-ден келген.
```

### 2-мысал:
```
Кіріс: nums1 = [1], m = 1, nums2 = [], n = 0
Шығыс: [1]
Түсіндірме: Біз біріктіретін массивтер [1] және [].
Нәтиже [1].
```

### 3-мысал:
```
Кіріс: nums1 = [0], m = 0, nums2 = [1], n = 1
Шығыс: [1]
Түсіндірме: Біз біріктіретін массивтер [] және [1].
Нәтиже [1].
Ескерту: m = 0 болғандықтан nums1-де элемент жоқ. 0 тек нәтиженің nums1-ге сыюы үшін тұр.
```

### Шектеулер:
- nums1.length == m + n
- nums2.length == n
- 0 <= m, n <= 200
- 1 <= m + n <= 200
- -10⁹ <= nums1[i], nums2[j] <= 10⁹

**Қосымша тапсырма:** **O(m + n)** уақытта жұмыс істейтін алгоритм ойлап таба аласыз ба?
