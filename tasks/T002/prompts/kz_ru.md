# 88. Біріктіру Sorted Array (Қазақша-орысша микс)

**Easy**  
Topics  
Companies  
Hint  

Сізге берілген екі integer массивы **nums1** және **nums2**, они отсортированы в non-decreasing order, и два целых числа **m** және **n**, которые представляют количество элементов в nums1 и nums2 соответственно.

Нужно merge nums1 и nums2 в один массив, отсортированный в non-decreasing order.

Финальный отсортированный массив **не** надо возвращать функцией, а надо сохранить внутри массива **nums1**. Чтобы это было возможно, nums1 имеет длину **m + n**, где первые **m** элементов — это те, что нужно мержить, а последние **n** элементов равны 0 и их надо игнорировать. nums2 имеет длину **n**.

### Пример 1:
```
Input: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
Output: [1,2,2,3,5,6]
Explanation: Массивтарды біз merge жасаймыз [1,2,3] және [2,5,6].
Результат merge = [1,2,2,3,5,6], где подчеркнутые элементы пришли из nums1.
```

### Пример 2:
```
Input: nums1 = [1], m = 1, nums2 = [], n = 0
Output: [1]
Explanation: Біз merge жасаймыз [1] және [].
Результат = [1].
```

### Пример 3:
```
Input: nums1 = [0], m = 0, nums2 = [1], n = 1
Output: [1]
Explanation: Біз merge жасаймыз [] және [1].
Результат = [1].
Обратите внимание: потому что m = 0, в nums1 элементов нет. Ноль там только для того, чтобы результат поместился в nums1.
```

### Constraints:
- nums1.length == m + n
- nums2.length == n
- 0 <= m, n <= 200
- 1 <= m + n <= 200
- -10⁹ <= nums1[i], nums2[j] <= 10⁹

**Follow up:** Можно ли придумать алгоритм, который работает за **O(m + n)** время?
