# Екі санның қосындысы (Two Sum)

Сізге `nums` бүтін сандар массиві және `target` бүтін саны берілген. Осы екі санның индекстерін қайтарыңыз, олардың қосындысы `target`-қа тең болатындай.

Әрбір енгізілімде **дәл бір шешім** бар деп есептеңіз және бір элементті екі рет қолдануға болмайды.

Жауапты кез келген ретпен қайтаруға болады.

## 1-мысал:

**Кіріс:** `nums = [2,7,11,15], target = 9`  
**Шығыс:** `[0,1]`  
**Түсіндірме:**  
`nums[0]` және `nums[1]` қосындысы `2 + 7 = 9`, бұл `target`-қа тең. Сондықтан индекстер `[0, 1]` қайтарылады.

## 2-мысал:

**Кіріс:** `nums = [3,2,4], target = 6`  
**Шығыс:** `[1,2]`  
**Түсіндірме:**  
`nums[1]` және `nums[2]` қосындысы `2 + 4 = 6`, бұл `target`-қа тең. Сондықтан индекстер `[1, 2]` қайтарылады.

## 3-мысал:

**Кіріс:** `nums = [3,3], target = 6`  
**Шығыс:** `[0,1]`  
**Түсіндірме:**  
`nums[0]` және `nums[1]` қосындысы `3 + 3 = 6`, бұл `target`-қа тең. Сондықтан индекстер `[0, 1]` қайтарылады.

## Шектеулер:

- `2 <= nums.length <= 10⁴`
- `-10⁹ <= nums[i] <= 10⁹`
- `-10⁹ <= target <= 10⁹`
- **Тек бір дұрыс жауап бар.**

**Қосымша тапсырма:** `O(n²)` уақыт күрделілігінен төмен алгоритм ойлап таба аласыз ба?
