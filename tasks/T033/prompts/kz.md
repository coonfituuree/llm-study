# B. Құрттар

Уақыт шектеуі: 1 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: stdin  
шығыс: stdout

Крот үшін түскі ас уақыты. Оның досы, Сурок, оған түскі асқа жақсы ойын дайындады.

Сурок Кротқа *n* реттелген құрт үйіндісін әкелді, мұнда *i*-ші үйінді *aᵢ* құрттан тұрады. Ол барлық құрттарды тізбектелген бүтін сандармен белгіледі: бірінші үйіндідегі құрттар 1-ден *a₁*-ге дейінгі сандармен, екінші үйіндідегі құрттар *a₁* + 1-ден *a₁* + *a₂*-ге дейінгі сандармен белгіленген және т.б. Жақсы түсіну үшін мысалды қараңыз.

Крот барлық құрттарды жей алмайды (Сурок көп әкелді) және, бәріміз білетіндей, Крот соқыр, сондықтан Сурок оған ең шырынды құрттардың белгілерін айтады. Сурок Кротқа құртты тек Крот осы құрттың қай үйіндіде екенін дұрыс айтса ғана береді.

Кедей Крот сізден көмек сұрайды. Сурок айтқан барлық шырынды құрттар үшін Кротқа дұрыс жауаптарды айтыңыз.

## Кіріс

Бірінші жолда бір бүтін сан *n* бар (1 ≤ *n* ≤ 10⁵), үйінділер саны.

Екінші жолда *n* бүтін сан *a₁*, *a₂*, ..., *aₙ* бар (1 ≤ *aᵢ* ≤ 10³, *a₁* + *a₂* + ... + *aₙ* ≤ 10⁶), мұнда *aᵢ* — *i*-ші үйіндідегі құрттар саны.

Үшінші жолда бір бүтін сан *m* бар (1 ≤ *m* ≤ 10⁵), Сурок айтқан шырынды құрттар саны.

Төртінші жолда *m* бүтін сан *q₁*, *q₂*, ..., *qₘ* бар (1 ≤ *qᵢ* ≤ *a₁* + *a₂* + ... + *aₙ*), шырынды құрттардың белгілері.

## Шығыс

Стандартты шығысқа *m* жолды шығарыңыз. *i*-ші жол *qᵢ* санымен белгіленген құрттың қай үйіндіде екенін білдіретін бүтін санды қамтуы керек.

## Мысалдар

**Кіріс**
```
5
2 7 3 4 9
3
1 25 11
```

**Шығыс**
```
1
5
3
```

## Ескерту

Мысал кірісі үшін:

- [1, 2] аралығындағы белгілері бар құрттар бірінші үйіндіде.
- [3, 9] аралығындағы белгілері бар құрттар екінші үйіндіде.
- [10, 12] аралығындағы белгілері бар құрттар үшінші үйіндіде.
- [13, 16] аралығындағы белгілері бар құрттар төртінші үйіндіде.
- [17, 25] аралығындағы белгілері бар құрттар бесінші үйіндіде.
