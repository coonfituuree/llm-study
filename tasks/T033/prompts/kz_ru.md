# B. Құрттар

Уақыт шектеуі: 1 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: stdin  
шығыс: stdout

Для Крота наступило время обеда. Его друг, Сурок, приготовил ему хорошую игру на обед.

Сурок принёс Кроту *n* упорядоченных куч червей, таких что *i*-я куча содержит *aᵢ* червей. Он пронумеровал всех этих червей последовательными целыми числами: черви в первой куче пронумерованы числами от 1 до *a₁*, черви во второй куче пронумерованы числами от *a₁* + 1 до *a₁* + *a₂* и так далее. Смотрите пример для лучшего понимания.

Крот не может съесть всех червей (Сурок принёс много) и, как мы все знаем, Крот слепой, поэтому Сурок говорит ему номера самых сочных червей. Сурок даст Кроту червя только если Крот правильно скажет, в какой куче находится этот червь.

Бедный Крот просит вашей помощи. Для всех сочных червей, названных Сурком, скажите Кроту правильные ответы.

## Кіріс

Первая строка содержит одно целое число *n* (1 ≤ *n* ≤ 10⁵), количество куч.

Вторая строка содержит *n* целых чисел *a₁*, *a₂*, ..., *aₙ* (1 ≤ *aᵢ* ≤ 10³, *a₁* + *a₂* + ... + *aₙ* ≤ 10⁶), где *aᵢ* — количество червей в *i*-ой куче.

Третья строка содержит одно целое число *m* (1 ≤ *m* ≤ 10⁵), количество сочных червей, названных Сурком.

Четвёртая строка содержит *m* целых чисел *q₁*, *q₂*, ..., *qₘ* (1 ≤ *qᵢ* ≤ *a₁* + *a₂* + ... + *aₙ*), номера сочных червей.

## Шығыс

Выведите *m* строк в стандартный вывод. *i*-я строка должна содержать целое число, представляющее номер кучи, где находится червь с номером *qᵢ*.

## Мысалдар

**Кіріс**
```
5
2 7 3 4 9
3
1 25 11
```

**Шығыс**
```
1
5
3
```

## Ескерту

Для примера ввода:

- Черви с номерами из [1, 2] находятся в первой куче.
- Черви с номерами из [3, 9] находятся во второй куче.
- Черви с номерами из [10, 12] находятся в третьей куче.
- Черви с номерами из [13, 16] находятся в четвёртой куче.
- Черви с номерами из [17, 25] находятся в пятой куче.
