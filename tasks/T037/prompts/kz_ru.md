# B. Екі батырма

Уақыт шектеуі: 2 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: standard input  
шығыс: standard output

Вася нашёл странное устройство. На передней панели устройства есть: красная кнопка, синяя кнопка и дисплей, показывающий некоторое положительное целое число. После нажатия красной кнопки устройство умножает отображаемое число на два. После нажатия синей кнопки устройство вычитает единицу из числа на дисплее. Если в какой-то момент число перестаёт быть положительным, устройство ломается. Дисплей может показывать сколь угодно большие числа. Изначально дисплей показывает число *n*.

Боб хочет получить число *m* на дисплее. Какое минимальное количество нажатий ему нужно сделать, чтобы достичь этого результата?

## Кіріс

Первая и единственная строка входных данных содержит два различных целых числа *n* и *m* (1 ≤ *n*, *m* ≤ 10⁴), разделённых пробелом.

## Шығыс

Выведите одно число — минимальное количество нажатий кнопки, необходимое чтобы получить число *m* из числа *n*.

## Мысалдар

**Кіріс**
```
4 6
```

**Шығыс**
```
2
```

**Кіріс**
```
10 1
```

**Шығыс**
```
9
```

## Ескерту

В первом примере нужно нажать синюю кнопку один раз, а затем красную кнопку один раз.

Во втором примере удваивать число не нужно, поэтому нужно нажать синюю кнопку девять раз.
