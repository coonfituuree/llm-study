# B. Екі батырма

Уақыт шектеуі: 2 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: standard input  
шығыс: standard output

Вася ерекше құрылғы тапты. Құрылғының алдыңғы панелінде: қызыл батырма, көк батырма және кейбір оң бүтін санды көрсететін дисплей бар. Қызыл батырманы басқаннан кейін құрылғы көрсетілген санды екіге көбейтеді. Көк батырманы басқаннан кейін құрылғы дисплейдегі саннан бірді азайтады. Егер қандай да бір сәтте сан оң болмай қалса, құрылғы бұзылады. Дисплей еркін үлкен сандарды көрсете алады. Бастапқыда дисплей *n* санын көрсетеді.

Боб дисплейде *m* санын алғысы келеді. Бұл нәтижеге жету үшін ол қанша минималды басу жасауы керек?

## Кіріс

Кірістің бірінші және жалғыз жолында екі әртүрлі бүтін сан *n* және *m* бар (1 ≤ *n*, *m* ≤ 10⁴), бос орынмен бөлінген.

## Шығыс

Бір санды шығарыңыз — *n* санынан *m* санын алу үшін батырманы басу қажетті минималды рет саны.

## Мысалдар

**Кіріс**
```
4 6
```

**Шығыс**
```
2
```

**Кіріс**
```
10 1
```

**Шығыс**
```
9
```

## Ескерту

Бірінші мысалда көк батырманы бір рет, содан кейін қызыл батырманы бір рет басу керек.

Екінші мысалда санды екіге көбейту қажет емес, сондықтан көк батырманы тоғыз рет басу керек.
