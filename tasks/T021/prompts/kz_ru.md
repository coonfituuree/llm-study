# A. Сөзді бас әріппен жазу

Уақыт шектеуі: 2 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: stdin  
шығыс: stdout

Бас әріппен жазу — это написание слова с первой буквы как заглавной. Ваша задача — капитализировать данное слово.

Ескерту: при капитализации все буквы кроме первой остаются без изменений.

## Кіріс

Одна строка содержит непустое слово. Это слово состоит из строчных и заглавных английских букв. Длина слова не превысит 10³.

## Шығыс

Выведите данное слово после капитализации.

## Мысалдар

**Кіріс**
```
ApPLe
```

**Шығыс**
```
ApPLe
```

**Кіріс**
```
konjac
```

**Шығыс**
```
Konjac
```
