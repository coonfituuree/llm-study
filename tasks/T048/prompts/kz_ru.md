# Бірінші жоқ оң сан

Сұрыпталмаған массив берілген.  
Нужно найти наименьшее отсутствующее положительное число. O(n) время, O(1) память.

## 1-мысал:
Кіріс: nums = [1,2,0]
Шығыс: 3

## 2-мысал:
Кіріс: nums = [3,4,-1,1]
Шығыс: 2

## 3-мысал:
Кіріс: nums = [7,8,9,11,12]
Шығыс: 1

## Шектеулер:
- 1 <= nums.length <= 10^5
