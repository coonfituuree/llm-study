# Сұрыпталған массивті Binary Search Tree-ге түрлендіру

## Тапсырма

Сізге строго возрастающем порядке сұрыпталған `nums` бүтін сандар массиві беріледі.

Оны height-balanced binary search tree-ге түрлендіру керек.

Ағаш теңгерілген болып саналады, егер әрбір node үшін сол және оң subtree биіктіктерінің айырмасы бірден артық болмаса.

`nums` массивіндегі барлық элементтерді қолдана отырып құрылған кез келген корректный height-balanced BST ағашының root мәнін қайтарыңыз.

## 1-мысал

```text
Input: nums = [-10, -3, 0, 5, 9]
Output: [0, -3, 9, -10, null, 5]
```

Сол элементтермен құрылған басқа корректный balanced BST те қабылданады.

## 2-мысал

```text
Input: nums = [1, 3]
Output: [3, 1]
```

`[1, null, 3]` варианты да дұрыс жауап болып саналады.

## Шектеулер

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` массиві строго возрастающем порядке сұрыпталған.
