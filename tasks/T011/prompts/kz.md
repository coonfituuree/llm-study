# Сұрыпталған массивті екілік іздеу ағашына түрлендіру

## Тапсырма

Сізге қатаң өсу ретімен сұрыпталған `nums` бүтін сандар массиві беріледі.

Оны биіктігі теңгерілген екілік іздеу ағашына түрлендіріңіз.

Биіктігі теңгерілген екілік ағашта әрбір төбе үшін сол және оң ішкі ағаштардың биіктіктерінің айырмасы бірден аспауы керек.

`nums` массивінен құрылған кез келген дұрыс теңгерілген BST ағашының түбірін қайтарыңыз.

## 1-мысал

```text
Кіріс: nums = [-10, -3, 0, 5, 9]
Шығыс: [0, -3, 9, -10, null, 5]
```

Осы мәндерден құрылған басқа дұрыс теңгерілген BST те қабылданады.

## 2-мысал

```text
Кіріс: nums = [1, 3]
Шығыс: [3, 1]
```

`[1, null, 3]` жауабы да дұрыс болып саналады.

## Шектеулер

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` қатаң өсу ретімен сұрыпталған.
