# Екі санды қосу (Add Two Numbers)

Сізге екі **бос емес** байланысқан тізім берілген, олар екі теріс емес бүтін санды білдіреді. Цифрлар **кері ретпен** сақталады, және әр түйін бір цифрды қамтиды. Екі санды қосып, қосындыны байланысқан тізім ретінде қайтарыңыз.

Екі санда жетекші нөл жоқ деп есептеңіз, тек 0 санының өзін қоспағанда.

## 1-мысал:
**Кіріс:** l1 = [2,4,3], l2 = [5,6,4]
**Шығыс:** [7,0,8]
**Түсіндірме:** 342 + 465 = 807.

## 2-мысал:
**Кіріс:** l1 = [0], l2 = [0]
**Шығыс:** [0]

## 3-мысал:
**Кіріс:** l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
**Шығыс:** [8,9,9,9,0,0,0,1]

## Шектеулер:
- Әр байланысқан тізімдегі түйіндер саны [1, 100] аралығында.
- 0 <= Node.val <= 9
- Тізім жетекші нөлсіз санды білдіреді.
