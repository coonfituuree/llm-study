# Екі санды қосу

Сізге екі **бос емес** байланысқан тізім берілген.  
Нужно сложить два числа, представленных связными списками в обратном порядке, и вернуть сумму тоже в виде связного списка.

Цифры хранятся в **обратном порядке**, каждый узел содержит одну цифру.

## 1-мысал:
Кіріс: l1 = [2,4,3], l2 = [5,6,4]
Шығыс: [7,0,8]
Түсіндірме: 342 + 465 = 807.

## 2-мысал:
Кіріс: l1 = [0], l2 = [0]
Шығыс: [0]

## 3-мысал:
Кіріс: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Шығыс: [8,9,9,9,0,0,0,1]

## Шектеулер:
- Число узлов в каждом списке [1, 100]
- 0 <= Node.val <= 9
