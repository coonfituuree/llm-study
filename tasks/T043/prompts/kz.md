# k сұрыпталған тізімді біріктіру

## Тапсырма

Сізге `k` байланысқан тізімнен тұратын `lists` массиві беріледі.

Әрбір байланысқан тізім өсу ретімен сұрыпталған.

Барлық тізімдерді бір сұрыпталған байланысқан тізімге біріктіріп, оның басын қайтарыңыз.

## Мысалдар

```text
Кіріс: lists = [[1,4,5],[1,3,4],[2,6]]
Шығыс: [1,1,2,3,4,4,5,6]
```

```text
Кіріс: lists = []
Шығыс: []
```

```text
Кіріс: lists = [[]]
Шығыс: []
```

## Шектеулер

- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- Әрбір `lists[i]` өсу ретімен сұрыпталған.
- Барлық тізімдердегі түйіндердің жалпы саны `10^4` мәнінен аспайды.
