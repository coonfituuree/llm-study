# Келесі кезең / Next Round

## Тапсырма

Жарысқа `n` участников қатысқан. Олардың score мәндері невозрастающем порядке берілген.

Қатысушы келесі кезеңге өтеді, егер:

1. оның score мәні `k`-орындағы участник ұпайынан кем болмаса;
2. оның score мәні положительный, яғни нөлден үлкен болса.

Келесі кезеңге өтетін участников санын анықтаңыз.

## Кіріс

Бірінші строкада `n` және `k` бүтін сандары беріледі.

Екінші строкада `n` бүтін сан беріледі — участников ұпайлары.

## Шығыс

Келесі кезеңге өтетін участников санын шығарыңыз.

## Шектеулер

- `1 <= k <= n <= 50`
- `0 <= ai <= 100`
- Scores невозрастающем порядке берілген.

## 1-мысал

```text
Input
8 5
10 9 8 7 7 7 5 5

Output
6
```

## 2-мысал

```text
Input
4 2
0 0 0 0

Output
0
```
