# Келесі кезең

## Тапсырма

Жарысқа `n` қатысушы қатысқан. Олардың ұпайлары кему ретімен берілген.

Қатысушы келесі кезеңге өтеді, егер:

1. оның ұпайы `k`-орындағы қатысушының ұпайынан кем болмаса;
2. оның ұпайы нөлден үлкен болса.

Келесі кезеңге өтетін қатысушылар санын анықтаңыз.

## Кіріс

Бірінші жолда `n` және `k` бүтін сандары беріледі.

Екінші жолда кему ретімен орналасқан `n` бүтін сан — қатысушылардың ұпайлары беріледі.

## Шығыс

Келесі кезеңге өтетін қатысушылар санын шығарыңыз.

## Шектеулер

- `1 <= k <= n <= 50`
- `0 <= ai <= 100`
- Ұпайлар кему ретімен берілген.

## 1-мысал

```text
Кіріс
8 5
10 9 8 7 7 7 5 5

Шығыс
6
```

## 2-мысал

```text
Кіріс
4 2
0 0 0 0

Шығыс
0
```
