# Жаңбыр суын ұстау

Сізге `n` теріс емес бүтін сан берілген, representing an elevation map where the width of each bar is `1`. Вычислите, сколько воды может удержать карта после дождя.

## 1-мысал:

**Кіріс:** height = [0,1,0,2,1,0,1,3,2,1,2,1]  
**Шығыс:** 6  
**Түсіндірме:** Карта высот (чёрная часть) представлена массивом [0,1,0,2,1,0,1,3,2,1,2,1]. В этом случае удерживается 6 единиц дождевой воды (синяя часть).

## 2-мысал:

**Кіріс:** height = [4,2,0,3,2,5]  
**Шығыс:** 9

## Шектеулер:

- n == height.length
- 1 <= n <= 2 * 10⁴
- 0 <= height[i] <= 10⁵
