# Жаңбыр суын ұстау

Әрбір жолақтың ені `1` болатын биіктік картасын білдіретін `n` теріс емес бүтін сан берілген, жаңбырдан кейін қанша су ұстай алатынын есептеңіз.

## 1-мысал:

**Кіріс:** height = [0,1,0,2,1,0,1,3,2,1,2,1]  
**Шығыс:** 6  
**Түсіндірме:** Жоғарыдағы биіктік картасы (қара бөлім) [0,1,0,2,1,0,1,3,2,1,2,1] массивімен берілген. Бұл жағдайда 6 бірлік жаңбыр суы (көк бөлім) ұсталады.

## 2-мысал:

**Кіріс:** height = [4,2,0,3,2,5]  
**Шығыс:** 9

## Шектеулер:

- n == height.length
- 1 <= n <= 2 * 10⁴
- 0 <= height[i] <= 10⁵
