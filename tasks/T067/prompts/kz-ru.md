# Су ағашы / Water Tree

## Тапсырма

`n` вершинадан тұратын rooted tree берілген. Корень — `1`-вершина. Әрбір вершина резервуар болып саналады және ол бос немесе заполнен водой болуы мүмкін.

Изначально барлық резервуарлар бос.

`q` операцияны ретімен орындау керек:

1. `1 v` — `v` вершинасын және оның бүкіл subtree бөлігін сумен толтыру.
2. `2 v` — `v` вершинасын және оның барлық предоктарын, кореньді қоса алғанда, босату.
3. `3 v` — `v` вершинасы қазіргі уақытта заполнена водой ма екенін тексеру.

Әрбір үшінші типтегі запрос үшін, егер `v` толы болса `1`, иначе `0` шығарыңыз.

## Кіріс

- Бірінші строкада `n` беріледі.
- Келесі `n - 1` строкада ағаштың edges мәндері беріледі.
- Келесі строкада `q` беріледі.
- Одан кейінгі `q` строкада `c v` форматындағы операции беріледі.

## Шектеулер

- `1 <= n <= 500000`
- `1 <= q <= 500000`
- Берілген graph — корені `1` болатын tree.
