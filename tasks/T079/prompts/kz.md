# Шұңқырлар

## Тапсырма

Бір қатарда орналасқан `N` шұңқыр берілген. Олар солдан оңға қарай `1`-ден `N`-ге дейін нөмірленген.

Әрбір `i` шұңқырының оң `a[i]` күші бар.

Егер доп `i` шұңқырына тасталса, ол бірден `i + a[i]` нөмірлі шұңқырға секіреді. Одан кейін де дәл сол ереже бойынша секіруін жалғастырады. Егер келесі шұңқырдың нөмірі `1..N` аралығынан тыс болса, доп қатардан шығып кетеді.

`M` операцияны орындау керек:

- `0 a b` — `a` шұңқырының күшін `b` мәніне өзгерту.
- `1 a` — допты `a` шұңқырына тастау.

Әрбір `1` түріндегі операция үшін:
1. доп қатардан шықпас бұрын барған соңғы шұңқыр;
2. доп жасаған секірулер саны

анықталуы керек.

## Кіріс

Бірінші жолда `N` және `M` бүтін сандары беріледі.

Екінші жолда шұңқырлардың бастапқы күштерін білдіретін `N` оң бүтін сан беріледі.

Келесі `M` жолда операциялар сипатталады.

## Шығыс

Әрбір `1` түріндегі операция үшін екі бүтін сан шығарыңыз:

```text
соңғы_шұңқыр секірулер_саны
```

## Шектеулер

- `1 <= N <= 100000`
- `1 <= M <= 100000`
- `1 <= a[i] <= N`
- Жаңарту операциясында `1 <= a, b <= N`

## Мысал

```text
Кіріс
8 5
1 1 1 1 1 2 8 2
1 1
0 1 3
1 1
0 3 4
1 2

Шығыс
8 7
8 5
7 3
```
