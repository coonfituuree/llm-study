# Шұңқырлар / Holes

## Тапсырма

Бір қатарда `N` шұңқыр орналасқан. Олар слева направо `1`-ден `N`-ге дейін нөмірленген.

Әрбір `i` шұңқырының положительная сила `a[i]` бар.

Егер допты `i` шұңқырына тастаса, ол сразу `i + a[i]` нөмірлі шұңқырға секіреді. Одан кейін дәл сол ереже бойынша прыжки жалғасады. Егер келесі шұңқырдың нөмірі `1..N` диапазонынан тыс болса, доп қатардан шығып кетеді.

`M` операцияны орындау керек:

- `0 a b` — `a` шұңқырының силу `b` мәніне өзгерту.
- `1 a` — допты `a` шұңқырына тастау.

Әрбір `1` типіндегі операция үшін:
1. доп шықпас бұрын барған последняя дырка;
2. жасаған прыжков саны

анықталуы керек.

## Кіріс

Бірінші строкада `N` және `M` беріледі.

Екінші строкада `N` положительных бүтін сан — шұңқырлардың бастапқы күштері беріледі.

Келесі `M` строкада операции беріледі.

## Шығыс

Әрбір `1` типіндегі операция үшін екі сан шығарыңыз:

```text
last_hole jumps
```

## Шектеулер

- `1 <= N <= 100000`
- `1 <= M <= 100000`
- `1 <= a[i] <= N`
- Update операциясында `1 <= a, b <= N`

## Мысал

```text
Input
8 5
1 1 1 1 1 2 8 2
1 1
0 1 3
1 1
0 3 4
1 2

Output
8 7
8 5
7 3
```
