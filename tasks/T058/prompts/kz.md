# 140. Сөздерді бөлу II

**Қиын**

`s` жолы және `wordDict` жолдар сөздігі берілген. `s`-ке бос орындар қосып, әр сөзі сөздіктегі жарамды сөз болатын сөйлем құрастырыңыз. Барлық осындай мүмкін сөйлемдерді **кез келген ретпен** қайтарыңыз.

**Ескерту:** сөздіктегі бір сөзді сегментацияда бірнеше рет қайталап пайдалануға болады.

### 1-мысал:
```
Кіріс: s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
Шығыс: ["cats and dog","cat sand dog"]
```

### 2-мысал:
```
Кіріс: s = "pineapplepenapple", wordDict = ["apple","pen","applepen","pine","pineapple"]
Шығыс: ["pine apple pen apple","pineapple pen apple","pine applepen apple"]
Түсіндірме: Сөздіктегі сөзді қайталап пайдалануға болады.
```

### 3-мысал:
```
Кіріс: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
Шығыс: []
```

### Шектеулер:
- 1 <= s.length <= 20
- 1 <= wordDict.length <= 1000
- 1 <= wordDict[i].length <= 10
- s және wordDict[i] тек кіші ағылшын әріптерінен тұрады.
- wordDict-тегі барлық жолдар **бірегей**.
- Жауаптың ұзындығы 10⁵-тен аспайтындай етіп кіріс жасалған.
