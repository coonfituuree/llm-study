# k топтағы түйіндерді кері бұру (Reverse Nodes in k-Group)

Байланысқан тізімнің `head`-і берілген. Тізім түйіндерін `k` топпен кері бұрып, өзгертілген тізімді қайтарыңыз.

`k` оң бүтін сан және тізім ұзындығынан үлкен емес. Егер түйіндер саны `k`-ға бөлінбесе, соңындағы қалған түйіндер өзгеріссіз қалады.

Түйін мәндерін өзгертуге болмайды, тек сілтемелерді өзгертуге болады.

## 1-мысал:
**Кіріс:** head = [1,2,3,4,5], k = 2
**Шығыс:** [2,1,4,3,5]

## 2-мысал:
**Кіріс:** head = [1,2,3,4,5], k = 3
**Шығыс:** [3,2,1,4,5]

## Шектеулер:
- Түйіндер саны n.
- 1 <= k <= n <= 5000
- 0 <= Node.val <= 1000
