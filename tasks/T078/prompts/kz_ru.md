# E. Қоршаудағы белгі

Уақыт шектеуі: 4 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: stdin  
шығыс: stdout

Чемпион Бизон жақында закончил покраску своего деревянного забора. Қоршау состоит из последовательности *n* панелей шириной 1 метр и произвольной высоты. Высота *i*-ой панели составляет *hᵢ* метров. Соседние доски следуют без зазора между ними.

После того как Бизон покрасил забор, он решил повесить на него табличку "продаётся". Белгі будет нарисована на прямоугольном листе бумаги и размещена на заборе так, чтобы стороны таблички были параллельны панелям забора и также совпадали с краями некоторых панелей. Чемпион Бизон ввёл следующие ограничения на позицию таблички:

1. Ширина таблички должна быть ровно *w* метров.
2. Белгі должна помещаться в сегмент забора от *l*-ой до *r*-ой панели включительно (также она не может выходить за границы забора в вертикальном направлении).

Табличка будет действительно красивой, поэтому Чемпион Бизон хочет, чтобы высота таблички была как можно больше.

Сізге описание забора и несколько запросов на размещение таблички берілген. Для каждого запроса выведите максимальную возможную высоту таблички, которую можно разместить на соответствующем сегменте забора с заданной фиксированной шириной таблички.

## Кіріс

Первая строка входных данных содержит целое число *n* — количество панелей в заборе (1 ≤ *n* ≤ 10⁵).

Екінші жолда *n* разделённых пробелами целых чисел *hᵢ* — высоты панелей (1 ≤ *hᵢ* ≤ 10⁹).

Третья строка содержит целое число *m* — количество запросов (1 ≤ *m* ≤ 10⁵).

Следующие *m* строк содержат описания запросов, каждый запрос представлен тремя целыми числами *l*, *r* и *w* (1 ≤ *l* ≤ *r* ≤ *n*, 1 ≤ *w* ≤ *r* - *l* + 1) — сегмент забора и ширина таблички соответственно.

## Шығыс

Для каждого запроса выведите ответ на отдельной строке — максимальную высоту таблички, которую можно поставить на соответствующем сегменте забора при выполнении всех условий.

## Мысалдар

**Кіріс**
```
5
1 2 2 3 3
3
2 5 3
2 5 2
1 5 5
```

**Шығыс**
```
2
3
1
```
