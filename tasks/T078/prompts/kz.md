# E. Қоршаудағы белгі

Уақыт шектеуі: 4 секунд  
Жад шектеуі: 256 мегабайт  
кіріс: stdin  
шығыс: stdout

Чемпион Бизон жақында ағаш қоршауын бояуды аяқтады. Қоршау ені 1 метр және еркін биіктіктегі *n* панельден тұрады. *i*-ші панельдің биіктігі *hᵢ* метр. Көршілес тақталар арасында бос орын жоқ.

Бизон қоршауды бояғаннан кейін оған "сатуға" белгісін қоюды шешті. Белгі тікбұрышты қағаз бетіне сызылады және қоршауға белгінің қабырғалары қоршау панельдеріне параллель және кейбір панельдердің шеттерімен тураланатындай етіп орналастырылады. Чемпион Бизон белгінің орналасуына келесі шектеулер енгізді:

1. Белгінің ені дәл *w* метр болуы керек.
2. Белгі қоршаудың *l*-ші панелінен *r*-ші панеліне дейінгі сегментке (қоса алғанда) сыюы керек (сондай-ақ ол тік бағытта қоршау шегінен аспауы керек).

Белгі өте әдемі болады, сондықтан Чемпион Бизон белгінің биіктігін мүмкіндігінше үлкен болғанын қалайды.

Сізге қоршаудың сипаттамасы және белгіні орналастыруға арналған бірнеше сұрау берілген. Әрбір сұрау үшін белгінің берілген енімен қоршаудың сәйкес сегментіне орналастыруға болатын максималды биіктігін шығарыңыз.

## Кіріс

Кірістің бірінші жолында бүтін сан *n* бар — қоршаудағы панельдер саны (1 ≤ *n* ≤ 10⁵).

Екінші жолда *n* бос орынмен бөлінген бүтін сан *hᵢ* бар — панельдердің биіктіктері (1 ≤ *hᵢ* ≤ 10⁹).

Үшінші жолда бүтін сан *m* бар — сұраулар саны (1 ≤ *m* ≤ 10⁵).

Келесі *m* жолда сұраулардың сипаттамалары бар, әрбір сұрау үш бүтін санмен *l*, *r* және *w* берілген (1 ≤ *l* ≤ *r* ≤ *n*, 1 ≤ *w* ≤ *r* - *l* + 1) — қоршау сегменті және белгінің ені сәйкесінше.

## Шығыс

Әрбір сұрау үшін жауапты жеке жолға шығарыңыз — барлық шарттар орындалған кезде қоршаудың сәйкес сегментіне қоюға болатын белгінің максималды биіктігі.

## Мысалдар

**Кіріс**
```
5
1 2 2 3 3
3
2 5 3
2 5 2
1 5 5
```

**Шығыс**
```
2
3
1
```

## Ескерту

Мысалдағы қоршау келесідей көрінеді:

Барлық сұраулар үшін белгілердің мүмкін позициялары төменде берілген.

Бірінші сұрау үшін белгінің оңтайлы позициясы. Екінші сұрау үшін белгінің оңтайлы позициясы. Үшінші сұрау үшін белгінің оңтайлы позициясы.
