# Тапсырма

Сізге екілік ағаштың `root` түбір түйіні беріледі. Түйіндердің мәндерін **симметриялық аралау (inorder traversal)** ретімен тізім ретінде қайтарыңыз: алдымен сол жақ ішкі ағашты, содан кейін ағымдағы түйінді, соңында оң жақ ішкі ағашты өңдеңіз. Егер `root` бос болса, `[]` қайтарыңыз.

## Интерфейс

Төмендегі әдістің сигнатурасын дәл сақтап, Python 3 тілінде шешім жазыңыз. Орындау ортасында `val`, `left`, `right` атрибуттары бар `TreeNode` класы беріледі; стандартты кірістен дерек оқудың қажеті жоқ.

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ...
```

## Шектеулер

- Түйіндер саны `0` мен `100` аралығында (шекаралары қоса есептеледі).
- Әр түйіннің мәні `-100` мен `100` аралығында (шекаралары қоса есептеледі).

## Мысалдар

```text
root = [4, 2, 5, 1, 3]  -> [1, 2, 3, 4, 5]
root = []               -> []
root = [-2, null, 5, 4] -> [-2, 4, 5]
```

Тек Python 3 тіліндегі іске асыру кодын қайтарыңыз.
