# 363B. Қоршау

**Уақыт шектеуі:** 1 секунд  
**Жад шектеуі:** 256 мегабайт

Поликарптың үйінің алдында қоршау бар. Қоршау бірдей ендігі *n* тақтайдан тұрады, олар солдан оңға қарай бір-бірінің артынан орналасқан. *i*-ші тақтайдың биіктігі *hᵢ* метр, әртүрлі тақтайлардың биіктігі әртүрлі болуы мүмкін.

Поликарп сәнді пианино сатып алып, оны үйге қалай кіргізуді ойлап жүр. Жоспарын жүзеге асыру үшін оған қоршаудан дәл *k* қатарынан тұратын тақтай алу керек. Биік тақтайларды жұлу қиынырақ, сондықтан Поликарп биіктіктерінің қосындысы мүмкіндігінше аз болатын *k* қатарынан тұратын тақтайларды тапқысы келеді.

Минималды жалпы биіктігі бар *k* қатарынан тұратын тақтайлардың индекстерін табатын программа жазыңыз. Назар аударыңыз, қоршау Поликарптың үйін қоршамайды, ол үйдің алдында (яғни қоршау циклді емес).

### Кіріс
Кірістің бірінші жолында *n* және *k* бүтін сандары бар (1 ≤ *n* ≤ 1.5·10⁵, 1 ≤ *k* ≤ *n*) — қоршаудағы тақтайлар саны және пианиноға арналған тесіктің ені. Екінші жолда *h₁, h₂, ..., hₙ* бүтін сандар тізбегі бар (1 ≤ *hᵢ* ≤ 100), мұнда *hᵢ* — қоршаудың *i*-ші тақтайының биіктігі.

### Шығыс
Мұндай *j* бүтін санын шығарыңыз, ол *j, j+1, ..., j+k-1* тақтайларының биіктіктерінің қосындысы мүмкіндігінше аз болады. Егер бірнеше осындай *j* болса, кез келгенін шығарыңыз.

### Мысалдар

**Кіріс**
```
7 3
1 2 6 1 1 7 1
```
**Шығыс**
```
3
```

### Ескерту
Мысалда сіздің міндетіңіз — биіктіктерінің қосындысы минималды болатын үш қатарынан тұратын тақтайларды табу. Берілген жағдайда 3, 4 және 5 индексті үш тақтай қажетті қасиетке ие, олардың жалпы биіктігі 8.
