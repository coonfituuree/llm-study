# Үш санның қосындысы

`nums` массиві берілген.  
Нужно найти все уникальные тройки, сумма которых равна 0.

## 1-мысал:
Кіріс: nums = [-1,0,1,2,-1,-4]
Шығыс: [[-1,-1,2],[-1,0,1]]

## 2-мысал:
Кіріс: nums = [0,1,1]
Шығыс: []

## 3-мысал:
Кіріс: nums = [0,0,0]
Шығыс: [[0,0,0]]

## Шектеулер:
- 3 <= nums.length <= 3000
- -10^5 <= nums[i] <= 10^5
