# Ең көп суы бар контейнер

Сізге ұзындығы `n` болатын `height` бүтін сандар массиві берілген. `n` тік сызық сызылған, мұнда `i`-ші сызықтың екі соңғы нүктесі `(i, 0)` және `(i, height[i])`.

X осімен бірге контейнер құрайтын екі сызықты табыңыз, контейнер ең көп суды қамтитындай.

*Контейнер сақтай алатын судың максималды мөлшерін* қайтарыңыз.

**Ескерту:** контейнерді еңкейтуге болмайды.

## 1-мысал:

**Кіріс:** height = [1,8,6,2,5,4,8,3,7]  
**Шығыс:** 49  
**Түсіндірме:** Жоғарыдағы тік сызықтар [1,8,6,2,5,4,8,3,7] массивімен берілген. Бұл жағдайда контейнер қамти алатын судың максималды ауданы (көк бөлім) 49.

## 2-мысал:

**Кіріс:** height = [1,1]  
**Шығыс:** 1

## Шектеулер:

- n == height.length
- 2 <= n <= 10⁵
- 0 <= height[i] <= 10⁴
