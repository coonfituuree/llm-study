# Ең көп суы бар контейнер

Сізге ұзындығы `n` болатын `height` бүтін сандар массиві берілген. Нарисованы `n` вертикальных линий, где два конца `i`-ой линии — это `(i, 0)` и `(i, height[i])`.

Найдите две линии, которые вместе с осью x образуют контейнер, такой что контейнер содержит больше всего воды.

Верните *максимальное количество воды, которое может хранить контейнер*.

**Ескерту:** контейнерді наклонять нельзя.

## 1-мысал:

**Кіріс:** height = [1,8,6,2,5,4,8,3,7]  
**Шығыс:** 49  
**Түсіндірме:** Вертикальные линии выше представлены массивом [1,8,6,2,5,4,8,3,7]. В этом случае максимальная площадь воды (синяя часть), которую может содержать контейнер, равна 49.

## 2-мысал:

**Кіріс:** height = [1,1]  
**Шығыс:** 1

## Шектеулер:

- n == height.length
- 2 <= n <= 10⁵
- 0 <= height[i] <= 10⁴
