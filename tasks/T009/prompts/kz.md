# Сұрыпталған массивтен қайталанатын элементтерді жою

**Өспейтін ретпен** сұрыпталған `nums` бүтін сандар массиві берілген. Қайталанатын элементтерді орнында жойыңыз, әрбір бірегей элемент тек **бір рет** кездесетіндей. Элементтердің **салыстырмалы реті** **бірдей** сақталуы керек.

`nums` ішіндегі *бірегей элементтердің* санын `k` деп есептеңіз. Қайталануларды жойғаннан кейін бірегей элементтердің санын `k` қайтарыңыз.

`nums` массивінің алғашқы `k` элементі бірегей сандарды **сұрыпталған ретпен** қамтуы керек. `k - 1` индексінен кейінгі қалған элементтерді елемеуге болады.

**Арнайы тексеру:**

Тексеруші сіздің шешіміңізді келесі кодпен тексереді:

```
int[] nums = [...]; // Кіріс массиві
int[] expectedNums = [...]; // Дұрыс ұзындықтағы күтілетін жауап

int k = removeDuplicates(nums); // Сіздің реализацияңызды шақырады

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
```

Егер барлық тексерулер өтсе, сіздің шешіміңіз **қабылданады**.

## 1-мысал:

**Кіріс:** nums = [1,1,2]  
**Шығыс:** 2, nums = [1,2,_]  
**Түсіндірме:** Сіздің функцияңыз k = 2 қайтаруы керек, nums массивінің алғашқы екі элементі сәйкесінше 1 және 2 болуы керек.  
Қайтарылған k-дан кейін не қалдыратыныңыз маңызды емес (сондықтан олар астын сызулар).

## 2-мысал:

**Кіріс:** nums = [0,0,1,1,1,2,2,3,3,4]  
**Шығыс:** 5, nums = [0,1,2,3,4,_,_,_,_,_]  
**Түсіндірме:** Сіздің функцияңыз k = 5 қайтаруы керек, nums массивінің алғашқы бес элементі сәйкесінше 0, 1, 2, 3 және 4 болуы керек.  
Қайтарылған k-дан кейін не қалдыратыныңыз маңызды емес (сондықтан олар астын сызулар).

## Шектеулер:

- 1 <= nums.length <= 3 * 10⁴
- -100 <= nums[i] <= 100
- nums **өспейтін** ретпен сұрыпталған.
