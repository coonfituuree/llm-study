# Сұрыпталған массивтен қайталанатын элементтерді жою

Сізге **өспейтін ретпен** сұрыпталған nums бүтін сандар массиві беріледі. Нужно удалить дубликаты in-place так, чтобы каждый уникальный элемент появлялся только **один раз**. Относительный порядок элементов должен сохраниться **тем же**.

Рассмотрите количество уникальных элементов в nums как k. После удаления дубликатов верните количество уникальных элементов k.

Алғашқы k элементі nums массивінің должны содержать уникальные числа в **отсортированном порядке**. Остальные элементы за индексом k - 1 можно игнорировать.

**Арнайы тексеру:**

Тексеруші сіздің шешіміңізді келесі кодпен тексереді:

```
int[] nums = [...]; // Кіріс массиві
int[] expectedNums = [...]; // Дұрыс ұзындықтағы күтілетін жауап

int k = removeDuplicates(nums); // Сіздің реализацияңызды шақырады

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
```

Егер барлық тексерулер өтсе, сіздің шешіміңіз **қабылданады**.

## 1-мысал:

**Кіріс:** nums = [1,1,2]  
**Шығыс:** 2, nums = [1,2,_]  
**Түсіндірме:** Сіздің функцияңыз k = 2 қайтаруы керек, с первыми двумя элементами nums равными 1 и 2 соответственно.  
Не важно, что вы оставите за пределами возвращённого k (поэтому они обозначены подчёркиваниями).

## 2-мысал:

**Кіріс:** nums = [0,0,1,1,1,2,2,3,3,4]  
**Шығыс:** 5, nums = [0,1,2,3,4,_,_,_,_,_]  
**Түсіндірме:** Сіздің функцияңыз k = 5 қайтаруы керек, с первыми пятью элементами nums равными 0, 1, 2, 3 и 4 соответственно.  
Не важно, что вы оставите за пределами возвращённого k (поэтому они обозначены подчёркиваниями).

## Шектеулер:

- 1 <= nums.length <= 3 * 10⁴
- -100 <= nums[i] <= 100
- nums сұрыпталған в **неубывающем** порядке.
