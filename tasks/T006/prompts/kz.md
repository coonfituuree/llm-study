# 12. Бүтін санды рим цифрына айналдыру

**Орташа**

Рим цифрларын жеті түрлі таңба білдіреді, олардың мәндері мынадай:

| Таңба | Мән  |
| ----- | ---- |
| I     | 1    |
| V     | 5    |
| X     | 10   |
| L     | 50   |
| C     | 100  |
| D     | 500  |
| M     | 1000 |

Рим цифрлары ондық орындардың мәндерін ең жоғарыдан ең төменгіге дейін қосу арқылы құрылады. Ондық орын мәнін рим цифрына айналдырудың келесі ережелері бар:

- Егер мән 4 немесе 9-дан басталмаса, енгізілген саннан шегеруге болатын максималды мәннің таңбасын таңдап, оны нәтижеге қосып, оның мәнін шегеріп, қалғанды рим цифрына айналдырыңыз.
- Егер мән 4 немесе 9-дан басталса, **шегеру формасын** қолданыңыз: бір таңба келесі таңбадан шегеріледі. Мысалы, 4 — бұл 1 (I) 5-тен (V) кем: IV, ал 9 — бұл 1 (I) 10-нан (X) кем: IX. Тек мына шегеру формалары қолданылады: 4 (IV), 9 (IX), 40 (XL), 90 (XC), 400 (CD) және 900 (CM).
- Тек 10-ның дәрежелері (I, X, C, M) қатарынан ең көп дегенде 3 рет қосылуы мүмкін. 5 (V), 50 (L) немесе 500 (D) бірнеше рет қосуға болмайды. Егер таңбаны 4 рет қосу керек болса, **шегеру формасын** қолданыңыз.

Берілген бүтін санды рим цифрына айналдырыңыз.

### 1-мысал:
```
Кіріс: num = 3749
Шығыс: "MMMDCCXLIX"
Түсіндірме:
3000 = MMM, өйткені 1000 (M) + 1000 (M) + 1000 (M)
 700 = DCC, өйткені 500 (D) + 100 (C) + 100 (C)
  40 = XL, өйткені 10 (X) 50-ден (L) кем
   9 = IX, өйткені 1 (I) 10-нан (X) кем
Ескерту: 49 — бұл 1 (I) 50-ден (L) кем емес, себебі түрлендіру ондық орындарға негізделген
```

### 2-мысал:
```
Кіріс: num = 58
Шығыс: "LVIII"
Түсіндірме:
50 = L
 8 = VIII
```

### 3-мысал:
```
Кіріс: num = 1994
Шығыс: "MCMXCIV"
Түсіндірме:
1000 = M
 900 = CM
  90 = XC
   4 = IV
```

### Шектеулер:
- 1 <= num <= 3999
