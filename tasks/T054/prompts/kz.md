# 84. Гистограммадағы ең үлкен тіктөртбұрыш

**Қиын**

Гистограмманың бағандарының биіктігін білдіретін `heights` бүтін сандар массиві берілген, әр бағанның ені `1`. Гистограммадағы ең үлкен тіктөртбұрыштың ауданын қайтарыңыз.

### 1-мысал:
```
Кіріс: heights = [2,1,5,6,2,3]
Шығыс: 10
Түсіндірме: Жоғарыда әр бағанның ені 1 болатын гистограмма көрсетілген.
Ең үлкен тіктөртбұрыш қызыл аймақта көрсетілген, оның ауданы = 10 бірлік.
```

### 2-мысал:
```
Кіріс: heights = [2,4]
Шығыс: 4
```

### Шектеулер:
- 1 <= heights.length <= 10⁵
- 0 <= heights[i] <= 10⁴
