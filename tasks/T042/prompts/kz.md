# 10. Тұрақты өрнек сәйкестігі

**Қиын**

Кіріс жолы `s` және үлгі `p` берілген. `'.'` және `'*'` қолдауы бар тұрақты өрнек сәйкестігін жүзеге асырыңыз:

- `'.'` кез келген бір таңбаға сәйкес келеді.
- `'*'` алдыңғы элементтің нөл немесе одан көп рет қайталануына сәйкес келеді.

Сәйкестік кіріс жолының **толық** бөлігін қамтитынын көрсететін boolean қайтарыңыз (ішінара емес).

### 1-мысал:
```
Кіріс: s = "aa", p = "a"
Шығыс: false
Түсіндірме: "a" "aa" жолының толық сәйкес келмейді.
```

### 2-мысал:
```
Кіріс: s = "aa", p = "a*"
Шығыс: true
Түсіндірме: '*' алдыңғы элементтің ('a') нөл немесе одан көп рет қайталануын білдіреді. Сондықтан 'a'-ны бір рет қайталап "aa" болады.
```

### 3-мысал:
```
Кіріс: s = "ab", p = ".*"
Шығыс: true
Түсіндірме: ".*" "кез келген таңбаның (.) нөл немесе одан көп (*) рет қайталануы" дегенді білдіреді.
```

### Шектеулер:
- 1 <= s.length <= 20
- 1 <= p.length <= 20
- s тек кіші ағылшын әріптерінен тұрады.
- p тек кіші ағылшын әріптерінен, '.' және '*'-тен тұрады.
- '*' таңбасының әр пайда болуында алдыңғы жарамды таңба болатынына кепілдік беріледі.
