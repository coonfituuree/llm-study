# Бірдей ағаш (Same Tree)

Екі бинарлық ағаштың түбірлері `p` және `q` берілген. Олардың бірдей екенін тексеретін функция жазыңыз.

Екі бинарлық ағаш бірдей деп есептеледі, егер олар құрылымдық жағынан бірдей болса және түйіндердің мәндері бірдей болса.

## 1-мысал:

**Кіріс:** `p = [1,2,3], q = [1,2,3]`  
**Шығыс:** `true`

## 2-мысал:

**Кіріс:** `p = [1,2], q = [1,null,2]`  
**Шығыс:** `false`

## 3-мысал:

**Кіріс:** `p = [1,2,1], q = [1,1,2]`  
**Шығыс:** `false`

## Шектеулер:

- Екі ағаштағы түйіндер саны `[0, 100]` аралығында.
- `-10⁴ <= Node.val <= 10⁴`
