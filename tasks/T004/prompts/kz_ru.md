# Бірдей ағаш

Екі бинарлық ағаштың түбірлері `p` және `q` берілген.  
Нужно написать функцию, которая проверяет, являются ли они одинаковыми.

Екі бинарлық ағаш бірдей деп есептеледі, егер они структурно идентичны и узлы имеют одинаковые значения.

## 1-мысал:

Кіріс: p = [1,2,3], q = [1,2,3]  
Шығыс: true

## 2-мысал:

Кіріс: p = [1,2], q = [1,null,2]  
Шығыс: false

## 3-мысал:

Кіріс: p = [1,2,1], q = [1,1,2]  
Шығыс: false

## Шектеулер:

- Число узлов в обоих деревьях находится в диапазоне [0, 100].
- -10⁴ <= Node.val <= 10⁴
