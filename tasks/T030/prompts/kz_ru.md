# Тиындарды ауыстыру

`coins` — номиналы монет, `amount` — сумма.
Нужно вернуть минимальное количество монет для набора суммы, либо -1.

## 1-мысал:
Кіріс: coins = [1,2,5], amount = 11
Шығыс: 3

## 2-мысал:
Кіріс: coins = [2], amount = 3
Шығыс: -1

## 3-мысал:
Кіріс: coins = [1], amount = 0
Шығыс: 0

## Шектеулер:
- 1 <= coins.length <= 12
- 0 <= amount <= 10^4
