# Тиындарды ауыстыру (Coin Change)

`coins` массивi — әртүрлі номиналдағы тиындар, `amount` — қажетті сома.

Соманы жинау үшін қажет **ең аз** тиын санын қайтарыңыз. Мүмкін болмаса `-1` қайтарыңыз.

Әр тиынды шексіз рет қолдануға болады.

## 1-мысал:
**Кіріс:** coins = [1,2,5], amount = 11
**Шығыс:** 3
**Түсіндірме:** 11 = 5 + 5 + 1

## 2-мысал:
**Кіріс:** coins = [2], amount = 3
**Шығыс:** -1

## 3-мысал:
**Кіріс:** coins = [1], amount = 0
**Шығыс:** 0

## Шектеулер:
- 1 <= coins.length <= 12
- 1 <= coins[i] <= 2^31 - 1
- 0 <= amount <= 10^4
