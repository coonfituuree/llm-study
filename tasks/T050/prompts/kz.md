# 44. Жабайы карта сәйкестігі

**Қиын**

Кіріс жолы (`s`) және үлгі (`p`) берілген. `'?'` және `'*'` қолдауы бар жабайы карта үлгісі сәйкестігін жүзеге асырыңыз:

- `'?'` кез келген бір таңбаға сәйкес келеді.
- `'*'` кез келген таңбалар тізбегіне сәйкес келеді (бос тізбекті қоса).

Сәйкестік кіріс жолының **толық** бөлігін қамтуы керек (ішінара емес).

### 1-мысал:
```
Кіріс: s = "aa", p = "a"
Шығыс: false
Түсіндірме: "a" "aa" жолының толық сәйкес келмейді.
```

### 2-мысал:
```
Кіріс: s = "aa", p = "*"
Шығыс: true
Түсіндірме: '*' кез келген тізбекке сәйкес келеді.
```

### 3-мысал:
```
Кіріс: s = "cb", p = "?a"
Шығыс: false
Түсіндірме: '?' 'c'-ға сәйкес келеді, бірақ екінші әріп 'a', ол 'b'-ға сәйкес келмейді.
```

### Шектеулер:
- 0 <= s.length, p.length <= 2000
- s тек кіші ағылшын әріптерінен тұрады.
- p тек кіші ағылшын әріптерінен, '?' немесе '*'-тен тұрады.
