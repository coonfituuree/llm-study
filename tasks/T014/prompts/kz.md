# 231A. Команда

**Уақыт шектеуі:** 2 секунд  
**Жад шектеуі:** 256 мегабайт

Бір күні үш ең жақсы дос Петя, Вася және Тоня команда құрып, программалау жарыстарына қатысуға шешім қабылдады. Программалау жарыстарында қатысушыларға әдетте бірнеше есеп ұсынылады. Жарыс басталмас бұрын достар есептің шешімін кемінде екеуі сенімді болса ғана жазатындарына келісті. Әйтпесе достар есептің шешімін жазбайды.

Бұл жарыста қатысушыларға *n* есеп ұсынылады. Әр есеп үшін қай дос шешімге сенімді екенін білеміз. Достарға шешім жазатын есептердің санын табуға көмектесіңіз.

### Кіріс
Бірінші жолда бір бүтін сан *n* (1 ≤ *n* ≤ 1000) — жарыстағы есептер саны. Содан кейін *n* жолда әрқайсысында үш бүтін сан бар, әрқайсысы 0 немесе 1. Егер жолдағы бірінші сан 1 болса, Петя есептің шешіміне сенімді, әйтпесе сенімді емес. Екінші сан Васяның пікірін, үшінші сан Тоняның пікірін көрсетеді. Жолдағы сандар бос орынмен бөлінген.

### Шығыс
Бір бүтін сан шығарыңыз — достар жарыста шешімін жазатын есептер саны.

### Мысалдар

**Кіріс**
```
3
1 1 0
1 1 1
1 0 0
```
**Шығыс**
```
2
```

**Кіріс**
```
2
1 0 0
0 1 1
```
**Шығыс**
```
1
```

### Ескерту
Бірінші мысалда Петя мен Вася бірінші есептің шешімін білетініне сенімді, ал екінші есептің шешімін үшеуі де біледі. Бұл олардың осы есептердің шешімін жазатынын білдіреді. Үшінші есептің шешіміне тек Петя ғана сенімді, бірақ бұл жеткіліксіз, сондықтан достар оны алмайды.

Екінші мысалда достар тек екінші есепті шешеді, өйткені Вася мен Тоня шешімге сенімді.
